카이사르 암호화 체험기

현대 컴퓨터 보안을 지탱하는 암호학은 결국 단순한 수학에서 출발했습니다.
로마 시대 군사 기밀을 전달하기 위해 만들어진 '카이사르 암호(Caesar Cipher)'를 통해 문자열(String)과 모듈러 연산(Modular Arithmetic)의 관계를 탐구해 봅니다.

01. Theory : 모듈러 연산과 데이터의 표현

컴퓨터는 문자를 직접 이해하지 못하고 숫자로 변환하여 처리합니다(예: ASCII 코드). 카이사르 암호도 마찬가지로 알파벳을 0부터 25까지의 숫자로 매핑합니다.

// 핵심 암호화 공식 E(x) = (x + n) mod 26
  • x: 평문의 문자 (A=0, B=1 ... Z=25)
  • n: 이동할 칸 수 (Shift Key)
  • mod 26: 26으로 나눈 나머지 연산. Z(25)를 넘어갈 경우 다시 A(0)로 돌아오게 만드는 핵심 수학 기법입니다.

암호학에서 컴퓨터 공학으로의 확장

카이사르 암호는 빈도 분석법에 의해 쉽게 해독된다는 한계가 있습니다. 하지만 이 단순한 '데이터 변환 규칙'과 '수학적 접근'은 현대 컴퓨터 과학으로 이어졌습니다.

오늘날 우리가 안전하게 웹사이트에 접속(HTTPS)하고 블록체인을 사용할 수 있는 이유는 소인수분해의 어려움을 이용한 RSA 암호나, 복잡한 비트 연산을 수행하는 AES 알고리즘이 있기 때문입니다. 컴퓨터 공학은 이처럼 수학적 상상력을 물리적 현실의 코드로 구현해 내는 학문입니다.
